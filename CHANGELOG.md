# Changelog

## 1.4.0

- Added NAS web deployment through Express and Docker.
- Added browser adapter for the existing renderer API.
- Added Dockerfile and docker-compose configuration.
- Added ZIP import/export support for the web service.
- Added versioned release archive support.
- Kept macOS Electron DMG packaging workflow.

## 1.3.0

- Added adjustable sidebar width.
- Added adjustable editor and preview split width.
- Added one-click editor collapse and preview expansion.
- Added ZIP import/export for desktop.
- Added folder drag ordering.

## 1.2.0

- Added tree-style folder and document management.
- Added folder creation, rename, delete, and document context menus.
- Improved long Markdown scrolling.

## 1.1.x

- Improved document rename and folder rename workflows.
- Fixed context menu actions.

## 1.0.0

- Initial Markdown Manager desktop application.
